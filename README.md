# 🍔 Food Retail Management System

A web-based Food Retail Management System developed using Java and Spring Boot.

## 🛠️ Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- HTML
- CSS
- JavaScript
- Docker

## ✨ Features

- Food/Product Management
- Add, Update and Delete Products
- Database Integration
- CRUD Operations
- Web-based Application
- Docker Support
