# 🍔 Food Retail Management System

A web-based Food Retail Management System developed using Java and Spring Boot.

## 📌 Project Description

The Food Retail Management System is a web-based application designed to manage food products and retail-related operations efficiently.

## 🛠️ Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- HTML
- CSS
- JavaScript
- Docker
- Git & GitHub

## ✨ Features

- Food/Product Management
- Add Products
- Update Products
- Delete Products
- View Products
- Database Integration
- CRUD Operations
- Web-based Application
- Docker Support

## ⚙️ How to Run

### 1. Clone the Repository

    git clone https://github.com/Abhinav13092005/food-retail-management-system.git

### 2. Open the Project

    cd food-retail-management-system

### 3. Configure the Database

Open:

    src/main/resources/application.properties

Configure your MySQL database details.

### 4. Run the Application

    mvnw.cmd spring-boot:run

### 5. Open in Browser

    http://localhost:8080
