# 🍴 Food Retail Management System

A web-based Food Retail Management System built using Java, Spring Boot, Spring Data JPA and MySQL.

## 🚀 Live Demo

👉 https://food-retail-management-system.onrender.com

## 💻 GitHub Repository

👉 https://github.com/Abhinav13092005/food-retail-management-system

## 🛠️ Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- REST API

## ✨ Features

- Add food products
- View food products
- Update food products
- Delete food products
- CRUD operations
- RESTful APIs
- MySQL database integration
